# Audio zu Text

Eine Website, die Audio- und Videodateien mit [Whisper](https://github.com/openai/whisper) in Text umwandelt – komplett im Browser. Keine Datei verlässt das Gerät.

- Läuft auf GitHub Pages, ohne Server und ohne API-Schlüssel
- Ausgabe als Text (TXT) und Untertitel (SRT), optional mit Sprecher-Erkennung
- Ausgelegt auf normale Office-Laptops (Chrome oder Edge)
